# Chocolate-Sales-Performance-Dashboard
About the Project

This dashboard was developed as part of a data analytics capstone project to analyze the sales performance of Sweet Delight Chocolate Ltd.

The goal was to turn raw sales data into meaningful insights that could help management understand business performance, identify growth opportunities, and support better decision-making.

What this Dashboard Covers

The dashboard includes seven interactive pages:

- Executive Overview
- Executive Dashboard
- Product Analysis
- Sales Performance
- Regional Analysis
- Time Intelligence
- Insights & Recommendations
  
Tools & Skills Used

- Power BI
- Power Query
- DAX
- Data Modelling
- Data Cleaning
- Data Visualization

Key Questions Answered

Some of the business questions explored in this project include:

- Which products generated the highest sales?
- Which regions performed best?
- How did sales change over time?
- What trends can management use for better decision-making?
- What recommendations can improve business performance?
